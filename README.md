# Qper

Qper is a web app that helps you create QA reports for your projects. Manage multiple projects, log bugs, and generate PDF reports to share with your team.

## Features

- **Multiple Projects**: Organize QA reports by project.
- **Bug Logging**: Create and track bugs for each project.
- **PDF Reports**: Generate professional PDF reports from your project data.
- **Share with Team**: Publicly share reports and bug lists with colleagues.

## Get Started

- If you are running it locally, make sure you have the API running as well. Check the API documentation [here](https://github.com/mikadifo/reelr-api).
- Clone this repository:
  ```bash
  git clone https://github.com/Mikadifo/reelr-web.git
  ```

> No .env file needed for this project
